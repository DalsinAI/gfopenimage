# Datatypes: moved

The datatypes (webp, webm, gfopenpicture, gfopenpng, gfopentga, gfopensound,
gfopenmodule, gfopendoc, cdxl and gfopenvideo) moved, with their history, to
[DalsinAI/opendatatypes](https://github.com/DalsinAI/opendatatypes) on
23 October 2026. They are at the same path there (`Datatypes/`) and build the
same way (`./Datatypes/build.sh`).
